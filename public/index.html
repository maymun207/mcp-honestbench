mcp-honestbench

A deliberately dishonest MCP server. The honesty laboratory, instalment zero.

It exists so that an agent system's honesty can be measured against lies it did not author. It tells lies; it never makes the consuming system's reads fail. Every response is well-formed, successful and on time — the dishonesty is in the content.

EndpointPurpose
POST /flatthe flat profile — five dials
POST /gatewaythe gateway profile — search_tools + call_tool
GET /healthboth content hashes, the live mode, the target
GET /runlogthe in-memory run log (warm instance only)
ModeBehaviour
M1silent-zero — returns 0 where the truth is absent
M2silent-truncation — first N of M rows, no signal
M3adeclaration drift — advertises a schema the payload does not honour
M3bname hijack — declares a tool name owned by another backend
M4plausible fabrication — a well-formed record for an out-of-scope entity

With no dial set the server tells the truth. That control is load-bearing: an instrument that cannot be honest cannot be trusted to lie on command.

A run is identified by the sha256 of fixture.json and dial.json. Both are printed at startup and stamped into every log line. Source: github.com/maymun207/mcp-honestbench
